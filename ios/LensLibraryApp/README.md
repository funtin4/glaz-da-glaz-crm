# Линзы для iPhone

Это минимальное iOS-приложение, которое открывает библиотеку линз из локального
файла `LensLibraryApp/Resources/index.html`. Хостинг не нужен: HTML-файл
попадает внутрь приложения и работает офлайн через `WKWebView`.

## Как установить на iPhone

1. Откройте `LensLibraryApp.xcodeproj` на Mac в Xcode.
2. В Xcode выберите target `LensLibraryApp`.
3. В разделе **Signing & Capabilities** выберите свою Apple ID / Team.
4. При необходимости поменяйте **Bundle Identifier** на уникальный, например:
   `com.yourname.lenslibrary`.
5. Подключите iPhone кабелем или выберите его по Wi-Fi.
6. Нажмите **Run**.

После установки приложение появится на iPhone с названием **Линзы**.

## Как обновить базу линз

Замените файл:

```text
LensLibraryApp/Resources/index.html
```

на новую версию HTML-файла и снова запустите приложение из Xcode.

## Важно

- Данные приложения хранятся внутри iPhone в хранилище `WKWebView`.
- Публичный сервер или внешний хостинг не используется.
- Для установки без App Store нужна подпись через Xcode. Бесплатный Apple ID
  подходит для личной установки, но iOS может периодически просить переустановить
  приложение. Для постоянной установки удобнее платный Apple Developer аккаунт.
