# 13. Источники (библиография)

**Дата доступа ко всем URL ниже:** 2026-07-24.  
**Продукт:** база знаний консультанта «Глаз Да Глаз» / Lens Path.

Приоритет при конфликте фактов: сверху вниз по разделу «Порядок приоритета».  
Маркеры надёжности:

| Маркер | Значение |
|--------|----------|
| `official_manufacturer` | Документация производителя линз |
| `association` | Проф. ассоциация / CET / ABO-ориентированные материалы |
| `peer_review` | Рецензируемые обзоры / систематические обзоры |
| `education` | Учебные гайды (вторичное образование, не primary research) |
| `distributor` | Страницы дистрибьюторов / прайсы |
| `marketing` | Рекламные обещания брендов и маркетплейсов |

---

## Порядок приоритета

1. `official_manufacturer` — IFU, dispensing guides, ограничения материалов и посадки.
2. `peer_review` — клинические утверждения (усталость, «защита», болезнь глаз).
3. `association` — согласованная практика диспенсинга (индекс, Abbe, материалы).
4. `education` — пояснения терминов; не использовать как единственный источник клиники.
5. `distributor` — цены, наличие, локальные названия; оптика — только как вторичное.
6. `marketing` — **не** источник клинических обещаний; максимум — формулировки конкурентов для анти-паттернов.

Внутренние прайсы салона (`data/raw/*.html`, `data/lenses.json`) — источник **SKU и цен**, не клинической истины.

## A. Производители (высокий приоритет)

### A1. Shamir — Lens Dispensing Guide

- **Тип:** `official_manufacturer`
- **URL:** https://shamir.com/wp-content/uploads/2022/12/SHA-DISGUIDE.pdf
- **Доступ:** 2026-07-24
- **Зачем:** практика выдачи линз Shamir; ограничения и рекомендации диспенсера; опора для семейств progressive / SV при работе с ассортиментом Shamir в прайсе.

### A2. Rodenstock — Progressive lenses, Instructions for Use

- **Тип:** `official_manufacturer`
- **URL:** https://www.rodenstock.com/fallback/dam/jcr:2316944c-682b-40a9-a059-7c21599f7236/instructions_for_use_rodenstock_progressive_lenses.pdf
- **Доступ:** 2026-07-24
- **Зачем:** обязательные параметры посадки прогрессивов, предупреждения IFU; нельзя обещать онлайн-заказ прогрессива «под ключ» без fitting.

### A3. Rodenstock — Tips & Technology 2022

- **Тип:** `official_manufacturer` (образовательно-технический материал бренда)
- **Название:** Rodenstock Tips & Technology 2022
- **Доступ:** 2026-07-24
- **Зачем:** терминология дизайнов, технологий покрытия/фотохрома в линейке Rodenstock; сверять white-label позиции в локальном прайсе с тем, что можно обещать клиенту.
- **Оговорка:** часть формулировок близка к продуктовому сторителлингу бренда — клинику не усиливать сверх IFU и независимых обзоров.

## B. Ассоциации и профессиональное образование

### B1. ABDO CET — refractive index (материалы CET)

- **Тип:** `association`
- **Домен:** https://www.abdo.org.uk/
- **Доступ:** 2026-07-24
- **Зачем:** связка refractive index ↔ толщина/вес; дисциплина не продавать высокий индекс без оптической необходимости.
- **Оговорка:** использовать как практику диспенсинга UK; локальные нормы РФ / процесс заказа — отдельно.

### B2. Opterio / ABO educational guides (index)

- **Тип:** `education`
- **Зачем:** вторичные учебные объяснения индекса, Abbe, материалов для консультантов.
- **Оговорка:** **не primary research**; при конфликте с manufacturer IFU или peer-review — уступают.

## C. Клиническая справочная база

### C1. AAO EyeWiki — Lens Material Properties

- **Тип:** `association` / клиническая энциклопедия AAO (не RCT, но курируемый справочник)
- **URL:** https://eyewiki.aao.org/Lens_Material_Properties
- **Доступ:** 2026-07-24
- **Зачем:** индекс преломления, Abbe, удельный вес, UV, сравнение CR-39 / polycarbonate / Trivex / high-index; основа для глоссария и объяснений «почему не всегда 1.74».

### C2. Cochrane — blue-light filtering spectacle lenses (systematic review)

- **Тип:** `peer_review`
- **Ключевые публикации / страницы:**
  - https://www.cochrane.org/evidence/CD013244_blue-light-filtering-spectacle-lenses-visual-performance-macular-back-part-eye-protection-and
  - https://www.cochranelibrary.com/cdsr/doi/10.1002/14651858.CD013244.pub2/abstract
  - PubMed: https://pubmed.ncbi.nlm.nih.gov/37593770/
- **Доступ:** 2026-07-24
- **Вывод для продукта:** клиническая польза blue-light filters для снижения eye strain, защиты макулы и улучшения сна — **неопределённа / не подтверждена** как основание для обещаний «защита» и «лечение». В клиентских текстах — только опция комфорта без медицинских гарантий.
- **Статус:** systematic review (Cochrane); использовать как стоп-фактор для маркетинговых формулировок текущего приложения.

## F. Анти-источники (не опираться)

- Гарантии толщины в мм без параметров оправы в любых блогах.
- Случайные Telegram-советы без первичного документа.
