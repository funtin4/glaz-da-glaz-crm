# 09. Оправа и толщина линз

**Продукт:** мастерская «Глаз Да Глаз» (Курск) — вставка линз в оправу клиента.  
**Назначение файла:** правила, которые нельзя нарушать в рекомендациях по толщине, диаметру заготовки и совместимости с оправой.

---

## 1. Главный принцип

Без параметров оправы и посадки **нельзя гарантировать** конечную толщину, вес и внешний вид линз.

Фото оправы в чате Авито — только **предварительная** оценка. Итог возможен после замера оправы и (для прогрессивов / асферики / безободковых) параметров посадки.

Формулировка клиенту:

> «По фото могу прикинуть варианты и ориентир по цене. Точную толщину и диаметр подберу, когда оправа будет у меня на столе (или пришлёте размеры с внутренней стороны дужки / коробки).»

---

## 2. Параметры оправы, влияющие на линзу

| Параметр | EN | Зачем нужен |
|----------|----|-------------|
| Горизонтальный проём (A / глаз) | A / eye size | Диаметр заготовки, децентрация, толщина края |
| Вертикальный проём (B) | B | Высота установки, особенно прогрессив / офис |
| DBL (перемычка) | DBL (distance between lenses) | Межцентровое расстояние оправы ≈ A + DBL |
| Форма светового проёма | Shape | Круг / овал / «кошачий глаз» / авиатор — разный запас по краю |
| Тип конструкции | Full-rim / semi-rimless / rimless | Мин. толщина края, материал, сверление |
| Угол изгиба (wrap) | Face form / wrap | Базовая кривизна, призматические эффекты, совместимость |
| Материаль оправы | Frame material | Термо / металл / титан / TR90 — усадка, нагрев, сверление |
| Толщина ободка / канавки | Groove / rim | Запас по краю, риск скола |

PD клиента (межзрачковое) сравнивают с геометрией оправы: **децентрация** = (A + DBL)/2 − PD/2 (упрощённо по каждому глазу). Чем больше децентрация и сильнее рецепт, тем заметнее толщина и вес.

---

## 3. Высота установки (fitting height)

Критична для:

- прогрессивных линз;
- офисных / indoor progressive;
- бифокалов (линия сегмента).

Без высоты и монокулярного PD онлайн можно дать только **оценку семейства линз и цены**, не финальный заказ прогрессива «под ключ».

---

## 4. Тип оправы → ограничения по линзе

### Полноободковая (full-rim)

- Самый «прощающий» тип.
- Допустимы стандартные края; проще скрыть толщину при минусе.
- Всё равно нужны A/B или фото + замер перед финалом.

### Полуободковая (semi-rimless / nylor)

- Нужен достаточный **min edge thickness** под леску/нить.
- Хрупкие высокие индексы и тонкий край — риск скола; решать мастеру.
- Не обещать «самые тонкие» без проверки края.

### Безободковая (rimless / drill mount)

- Сверление: материал должен допускать drill (часто поликарбонат, Trivex, ряд mid/high-index — по каталогу поставщика).
- Минимальная толщина в зоне отверстия — по IFU/каталогу; типично выше, чем у full-rim.
- Низкий индекс при высокой коррекции визуально «тяжёлый» и хуже держит крепёж.
- Онлайн: только предварительный список допустимых материалов; финал — после осмотра оправы.

### Wrap / спортивные

- Высокий face-form angle → нужна совместимая базовая кривизна и часто RX-расчёт.
- Обычные «плоские» стоки могут не сесть или дать оптические искажения.
- Эскалация уровню C (см. `12-safety-and-escalation.md`), если wrap выраженный.

---

## 5. Диаметр заготовки (blank diameter)

Заготовка должна покрывать весь проём с запасом на децентрацию и обработку.

Факторы увеличения диаметра:

- крупный A;
- сильная децентрация (узкий PD при широкой оправе);
- высокая |SPH| / |CYL| (призматический и толщинный запас);
- асферика / прогрессив (ограничения центрирования).

Недостаток диаметра → брак, сдвиг оптического центра, невозможность выдержать PD.

В прайсах поставщиков (Shamir, Maxxee, Rodenstock WL, Weiya) диаметр часто указан грубо («70/75») или отсутствует детализация под конкретный проём — **не подставлять «гарантированный диаметр» в клиентский текст**.

---

## 6. Минимальная толщина края (min edge thickness)

Зависит от:

- типа оправы (rimless / nylor vs full-rim);
- материала линзы;
- требований производителя к сверлению и канавке;
- политики салона (запас прочности).

Правило продукта:

1. Не обещать «линзы будут X мм по краю».
2. Можно сказать: «в вашей оправе сделаем так, чтобы край держал крепёж / леску — без опасного утоньшения».
3. Числовые пороги (мм) — только после утверждения владельцем (см. `15-open-questions.md`).

---

## 7. Что влияет на воспринимаемую толщину

| Фактор | Влияние |
|--------|---------|
| |SPH|, |CYL|, ADD | Сильнее коррекция → толще/тяжелее при том же индексе |
| Индекс преломления | Выше индекс → тоньше *при прочих равных*, но не «волшебство» |
| Асферический дизайн | Часто лучше косметика и меньше краевых искажений |
| Размер и форма оправы | Крупная/угловатая оправа «съедает» выигрыш высокого индекса |
| Децентрация | Увеличивает толщину на височном/носовом крае |
| PD vs геометрия оправы | Ключ к реальной толщине, не только «индекс из прайса» |
| Покрытие / фотохром | Слабо влияет на мм; влияет на цену и массу чуть |

**Ошибка апсейла:** предлагать 1.67 / 1.74 при низкой коррекции «чтобы было тоньше» без учёта оправы — клиент платит больше без заметного эффекта. Продавать **аккуратный вид в оправе**, а не цифру индекса.

## 8. Фото оправы: что можно и нельзя

**Можно (уровень B — предварительный):**

- тип: full / semi / rimless (если видно);
- ориентировочно крупная / средняя / мелкая;
- металл / пластик (грубо);
- отсечь заведомо несовместимые семейства (например, агрессивный wrap).

**Нельзя:**

- назвать точную толщину в мм;
- гарантировать «будут как на картинке в рекламе»;
- финализировать прогрессив без высоты и PD;
- обещать срок «точно завтра», если диаметр/материал не подтверждены.

---

## 9. Правила для движка рекомендаций (безопасные формулировки)

Разрешено онлайн:

- спрашивать тип оправы (3–4 варианта) + «оправа будет у вас / привезу»;
- повышать рекомендуемую «тонкость» при высокой |SPH| **как мягкий приоритет**, не как гарантию мм;
- для rimless — предпочитать материалы/индексы, допускающие сверление (список — после утверждения владельцем).

Запрещено онлайн без замеров:

- «гарантированная толщина»;
- «самые тонкие из возможных» без оговорки;
- расчёт blank diameter «в лоб» по одному SPH;
- утверждение, что фото достаточно для финального заказа сложных линз.

---

## 10. Чеклист мастера перед финальным заказом

1. Рецепт (SPH/CYL/AXIS/ADD, дата, PD если есть).
2. A, B, DBL или трассировка / шаблон.
3. Тип оправы и состояние (трещины, износ канавки).
4. PD (монокулярно для прогрессива) + высота.
5. Материал оправы / возможность нагрева и сверления.
6. Согласованный индекс, дизайн, покрытие, фотохром.
7. Клиенту озвучена **ориентировочная** цена пары + работа; финал после подтверждения поставки.
