# Вопросы клиенту (пересмотр анкеты)

Цель: минимум вопросов → полезный подбор. Не спрашивать то, чего клиент не знает.

## Принципы
- Один вопрос = одно решение в правилах.
- Можно пропускать, если ответ уже следует из канала (Авито: рецепт у мастера).
- Формулировки — язык частного мастера, не клиника.

## Предлагаемый минимальный набор (Avito-first)

| ID | Вопрос клиенту | Зачем | Влияет на | Можно пропустить? |
|----|----------------|-------|-----------|-------------------|
| Q1 | Очки в основном для чего? (всегда / даль / чтение / компьютер / руль / работа / не знаю) | Тип линзы и сценарий | lens_type family, scoring use-case | Нет (или default «не знаю») |
| Q2 | Оправа какая? (с ободком / на леске / на винтиках / пока нет) | Толщина, rimless, labor | thinness, rimless_relevance, labor | Да → unknown, уровень B по толщине |
| Q3 | Что важнее сейчас? (недорого / потоньше / комфорт / экраны / хамелеон / меньше бликов / готовы доплатить за лучшее) | Приоритет портфеля | weights, photo hard, coating | Нет |
| Q4 | Линзы сами темнеют на улице? (да / нет / не знаю) | Фотохром | hard photo filter | Да, если Q3=хамелеон |
| Q5 | На линзы примерно сколько? | Бюджет | budget filter, tier packing | Да → без потолка |
| Q6 | Часто за рулём днём? (да / нет) | Фотохром в авто, polar/drive | driving_relevance, photo warnings | Да; обязателен если Q1=руль или Q4=да |

### Условные (не в основной анкете)
| ID | Вопрос | Когда |
|----|--------|-------|
| Q7 | Сколько часов в день у экрана? | Q1=компьютер/работа или Q3=экраны |
| Q8 | Были ли проблемы с прошлыми очками? (толстые / блики / «плавает» / долго привыкал) | Всегда опционально; для progressive — важно |
| Q9 | Возраст (примерно) | Только если нет ADD и есть сомнение office/progressive — **не единственное основание** |

## Плохие вопросы (запрещены в клиентском UI)
- Какой индекс? Какое покрытие? Какой коридор? Freeform или нет?

## Рецепт
- На Авито клиент **не заполняет** SPH-форму, если мастер уже ввёл рецепт в сессию.
- Без рецепта: уровень C или «пришлите фото листочка» — не полноценный подбор.

## Связь с уровнями A/B/C
- A: Q1–Q5 + полный простой SV-рецепт + понятная оправа.
- B: нет размеров оправы / нет PD / office-оценка / photo «не знаю».
- C: progressive final, дети, призма, высокий сложный рецепт, нечитаемый Rx.
