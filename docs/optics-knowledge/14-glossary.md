# 14. Глоссарий

Краткий русскоязычный словарь для консультанта и будущих агентов.  
В скобках — исходный английский термин.

---

## Рецепт и коррекция

| RU | EN | Смысл |
|----|----|-------|
| Сфера | Sphere (SPH) | Основная оптическая сила, дптр |
| Цилиндр | Cylinder (CYL) | Сила коррекции астигматизма |
| Ось | Axis | Ориентация цилиндра, 1–180° |
| Аддидация | Addition (ADD) | Добавка для близи (пресбиопия) |
| Межзрачковое расстояние | Pupillary distance (PD) | Расстояние между центрами зрачков |
| Монокулярный PD | Monocular PD | PD отдельно OD/OS |
| Пресбиопия | Presbyopia | Возрастное снижение аккомодации для близи |
| Астигматизм | Astigmatism | Разная сила в меридианах |
| Анизометропия | Anisometropia | Существенная разница коррекции между глазами |
| Диоптрия | Diopter (D) | Единица оптической силы |
| OD / OS / OU | Oculus dexter / sinister / uterque | Правый / левый / оба глаза |

## Типы линз

| RU | EN | Смысл |
|----|----|-------|
| Однофокальные | Single vision (SV) | Одна зона коррекции |
| Прогрессивные | Progressive addition lenses (PAL) | Плавный переход даль → промежуток → близь |
| Бифокальные | Bifocal | Две зоны, видимая линия сегмента |
| Офисные / indoor | Occupational / office / indoor progressive | Акцент на среднюю и близь; не замена для дали/улицы без оговорок |
| Фотохромные («хамелеон») | Photochromic | Темнеют под UV / при ярком свете |
| Поляризационные | Polarized | Режут блики от горизонтальных поверхностей |
| Асферические | Aspheric | Уплощённый дизайн, часто лучше косметика и краевая оптика |
| Сток | Stock lens | Складская заготовка готовых диоптрий |
| Рецептурные (RX) | Surfaced / Rx lens | Изготовление под заказ |

## Материалы и оптика линзы

| RU | EN | Смысл |
|----|----|-------|
| Индекс преломления | Refractive index (n) | Чем выше, тем тоньше линза *при прочих равных* |
| Число Аббе | Abbe number (V) | Мера хроматической дисперсии; ниже → больше риск «радуги» |
| Удельный вес | Specific gravity | Влияет на массу линзы |
| CR-39 | CR-39 | Классический пластик ~1.50 |
| Поликарбонат | Polycarbonate | Ударопрочный, низкий Abbe |
| Trivex | Trivex | Лёгкий, ударопрочный, выше Abbe чем у PC |
| Высокий индекс | High-index | Обычно n ≥ 1.60 |
| Заготовка / бланк | Blank | Круглая заготовка до обработки |
| Диаметр заготовки | Blank diameter | мм; должен покрыть проём с запасом |
| Базовая кривизна | Base curve | Кривизна фронтальной поверхности |
| Мин. толщина края | Minimum edge thickness | Критично для nylor/rimless |
| Центр / край | Center / edge thickness | Косметика и прочность |

## Оправа и посадка

| RU | EN | Смысл |
|----|----|-------|
| Проём (горизонталь) | A / eyesize | Ширина светового отверстия |
| Проём (вертикаль) | B | Высота светового отверстия |
| Перемычка | DBL (distance between lenses) | Расстояние между линзами |
| Форма проёма | Lens shape / aperture | Контур оправы |
| Полноободковая | Full-rim | Линза в ободке |
| Полуободковая / на леске | Semi-rimless / nylor | Частичная фиксация нитью |
| Безободковая | Rimless / drill-mount | Крепление через сверление |
| Изгиб оправы | Wrap / face-form angle | «Обхват» лица; влияет на оптику |
| Высота установки | Fitting height | От низа линзы до зрачка (PAL) |
| Децентрация | Decentration | Смещение оптического центра vs геометрического |
| Канавка | Groove | Паз под линзу в ободке |
| Трассировка | Frame tracer | Снятие контура оправы |

## Покрытия и опции

| RU | EN | Смысл |
|----|----|-------|
| Просветление / антиблик | Anti-reflective (AR) coating | Меньше отражений |
| Мультипокрытие | Multicoat / hard multicoat (HMC и др.) | Набор слоёв: твёрдость, AR, гидрофоб и т.д. |
| Упрочняющее | Scratch-resistant / hard coat | Стойкость к царапинам (не «нецарапаемые») |
| Гидрофобное / олеофобное | Hydrophobic / oleophobic | Проще очищать |
| UV-защита | UV protection | Блокировка ультрафиолета материалом/покрытием |
| Фильтр синего | Blue-light filter | Опция комфорта; **не** доказанная «защита от болезни» |
| Тонировка | Tint | Окрашивание |
| Drive-фотохром | Extra-dark / automotive-oriented photochromic | Серии, лучше работающие в авто — уточнять по бренду |

## Язык «клиенту» vs «мастеру»

Не путать слои:

- Клиенту: «потоньше», «меньше бликов», «и вдаль и вблизь».
- Мастеру: SPH, index 1.60, AR level, blank Ø, fitting height.
