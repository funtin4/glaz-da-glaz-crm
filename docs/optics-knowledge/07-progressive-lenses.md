# 07. Прогрессивные линзы

Документ для базы знаний цифрового консультанта.  
**Онлайн может предлагать только класс и ценовой диапазон**, не финальный progressive-заказ без измерений.

Разметка: **FACT** / **EXPERT_JUDGMENT** / **UNKNOWN / requires_verification**.

---

## 1. ADD и зоны

### FACT

Прогрессив (PAL) содержит плавный переход:
- **зона дали** (верх);
- **коридор / intermediate** (середина);
- **зона близи** (низ), где действует ADD. [SRC-PROG-002]

**ADD** — аддидация близи из рецепта. Ширина и длина полезных зон зависят от дизайна, коридора, оправы и разметки. [SRC-PROG-001]

Периферия содержит зоны нежелательного астигматизма прогрессива — источник «плавания» при адаптации. [SRC-PROG-003]

---

## 2. Коридор (corridor length)

### FACT

Длина зоны перехода даль→близь. Короткий коридор — для малых вертикальных размеров оправы; длинный — шире mid, но нужна высота. [SRC-PROG-004]

### EXPERT_JUDGMENT

Подбор длины коридора **нельзя** финализировать по фото оправы без fitting height.

---

## 3. Адаптация

### FACT / EXPERT_JUDGMENT

Большинству клиентов нужен период привыкания (дни–недели). Неудачная разметка, неверный PD/высота, неподходящая оправа или скачок ADD повышают риск отказа. [SRC-PROG-005]

### Бан фраз

«Привыкнете за один вечер», «без искажений», «идеально сразу».

### Допустимо

«Обычно есть период адаптации; при сильном дискомфорте — проверка посадки у мастера».

---

## 4. Standard vs individual

### FACT

| Класс | Что заложено |
|-------|----------------|
| **Standard / stock progressive** | Типовые параметры дизайна |
| **Optimized / mid freeform** | Лучше распределение аберраций; часть параметров |
| **Individual** | Персональные PD, высота, CVD, tilt, wrap (± доминантность, данные оправы) |

Бренды: **Shamir** (e.g. Autograph family — уточнять прайс), **Rodenstock** Impression/Multigressiv и др., **ZEISS** Individual, **Essilor** Varilux индивидуальные, **Hoya** Lifestyle/Individual — конкретные имена сверять с прайсом салона. [SRC-PROG-006]

### Rodenstock IFU — стандартные параметры, если individual не заказан

Ориентиры (проверять актуальный IFU):  
- pantoscopic tilt (**PT**) ≈ **8°**  
- face form angle (**FFA**) ≈ **5°**  
- corneal vertex distance (**CVD**) ≈ **13 mm**  

[SRC-ROD-IFU-001]

### Онлайн-правило (жёсткое)

Выдача: **класс** (entry / mid / individual) + **price range**.  
Не утверждать: «вам уже подобран Rodenstock Impression с вашими 8°/5°/13 mm» — это defaults, не измерения клиента.

---

## 5. Fitting height (высота установки)

### FACT

Вертикальное расстояние от нижней точки проёма (или иной референс лаборатории) до центра зрачка в положении ношения. Критично для попадания в зоны дали/близи. [SRC-PROG-007]

Минимальная высота монтажа (**min mounting height**) задаётся дизайном; оправа ниже минимума → другой дизайн или другая оправа. [SRC-PROG-008]

---

## 6. CVD, pantoscopic tilt, wrap

### FACT

| Параметр | Смысл |
|----------|--------|
| **CVD** | Зазор роговица–линза |
| **Pantoscopic tilt** | Наклон плоскости линзы в вертикали |
| **Wrap / FFA** | Изгиб оправы по лицу |

Влияют на эффективную силу и оптимизацию freeform. [SRC-PROG-009]

Без них — стандартные подстановки лаборатории/бренда.

---

## 7. Форма оправы

### FACT / EXPERT_JUDGMENT

Узкие, «кошачий глаз», сильно смещённый проём, высокий wrap — риск узких зон и сложных progressives. Спортивные wrap-оправы часто **не** лучший носитель первого прогрессива.

Практичный совет онлайн: «нужна очная оценка оправы под прогрессив».

---

## 8. Сбои адаптации — типовые причины (EXPERT_JUDGMENT)

1. Ошибка PD / высоты / перекос оправы  
2. Слишком короткий коридор в мелкой оправе  
3. Резкий рост ADD без промежуточного опыта  
4. Неверные ожидания (чтение лёжа, работа только на 2 м без опускания взгляда)  
5. Анизометропия / призма без учёта  
6. Старый рецепт  

Действие продукта: при жалобе на «не могу привыкнуть» → **эскалация мастеру**, не «ещё один SKU наугад».

---

## 9. Budget vs premium — в чём разница (EXPERT_JUDGMENT)

| | Budget / entry | Premium / individual |
|--|----------------|----------------------|
| Зоны | Уже / больше «плавания» | Шире полезное поле (типично) |
| Параметры | Standards | Измеренные |
| Оправа | Требовательнее к размеру | Гибче за счёт оптимизации |
| Цена | Ниже | Выше |
| Обещание | «Рабочий прогрессив» | «Расчёт под посадку» — только после измерений |

Не обещать, что premium = нулевая адаптация.

---

## 10. Вопросы консультанта

1. Первый прогрессив или замена привычного?
2. Нужна ли даль на улице и за рулём в этих очках? (иначе см. office)
3. Основная работа: монитор / документы / смешанно?
4. Готовность прийти на разметку?
5. Размер/тип оправы уже выбран?
6. Бюджетный коридор пары?

---

## 11. Портфель practical / optimal / premium

| Уровень | Смысл |
|---------|--------|
| **Practical** | Entry progressive class + необходимый индекс по Rx; price **range** |
| **Optimal** | Mid freeform; лучшие покрытия |
| **Premium** | Individual class + top coat; акцент «после измерений» |

Все три — с дисклеймером измерений. Альтернативный путь в выдаче: office (если задача indoor) — см. `08-office-lenses.md`.

---

## 12. Эскалация (requires_owner_approval как config)

Черновики порогов:
- ADD есть, измерений нет → не финальный заказ  
- возраст < 14 → не взрослый PAL из прайса  
- призма → очно  
- \|\| анизометропия \|\| высокая → очно
