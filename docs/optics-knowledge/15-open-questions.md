## 1. Пороги рекомендаций

- [x] С какого \|SPH\| поднимаем к индексу ≥ 1.60?
- [x] С какого \|SPH\| 1.67? Когда 1.74?
- [x] 1.50–1.56 — до какого \|SPH\|?

**Ответ владельца (2026-07-24):**
- **1.60** — можно рекомендовать **даже с ~0 D**; «хуже не сделает».
- **1.50–1.56** — рекомендовать **максимум до ±3.0 D** (как потолок для этой группы индексов в автоподборе).
- **1.67** — **почти обязателен** при диоптриях **от ±4.0…±5.0**.
- **1.74** — отдельно не задано → в конфиге `needs_clarification`; до уточнения не оверселлить при низком Rx.

**Ответ владельца:** заполнен (кроме точного порога 1.74)
