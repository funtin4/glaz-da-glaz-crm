# 01. Основы рецепта на очковые линзы

Документ для базы знаний цифрового консультанта (Lens Path / частный мастер, подбор через Авито).  
**Не является медицинской диагностикой и не заменяет осмотр врача-офтальмолога или оптометриста.**

Разметка утверждений:
- **FACT** — устоявшееся определение/практика оптики
- **EXPERT_JUDGMENT** — экспертная оценка для рекомендаций и эскалации
- **UNKNOWN / requires_verification** — требует проверки источником или владельцем продукта
- **requires_owner_approval** — порог конфигурации; не выдавать как абсолютную медицинскую норму

---

## 1. Глаза и обозначения

### FACT

| Обозначение | Значение |
|-------------|----------|
| **OD** (oculus dexter) | Правый глаз |
| **OS** (oculus sinister) | Левый глаз |
| **OU** (oculi uterque) | Оба глаза |

На бланке рецепта параметры чаще указывают отдельно для OD и OS. Если стоит OU — параметры одинаковы для обоих глаз. [SRC-RX-001]

---

## 2. SPH, CYL, AXIS

### FACT

- **SPH (sphere)** — сферическая составляющая рефракции, в диоптриях (D). «−» — миопия (минусовые линзы), «+» — гиперметропия (плюсовые). [SRC-RX-002]
- **CYL (cylinder)** — цилиндрическая составляющая (астигматизм), в D. Может отсутствовать или быть «0» / «plano» / «sph». [SRC-RX-002]
- **AXIS** — ось цилиндра, 0–180° (иногда пишут 1–180). Имеет смысл только при ненулевом CYL. [SRC-RX-002]

Транспозиция цилиндра (перевод «−» ↔ «+» формы) меняет SPH, CYL и AXIS по правилам оптики; итоговая коррекция эквивалентна. [SRC-RX-003]

### EXPERT_JUDGMENT

Для цифрового консультанта безопаснее хранить рецепт в **одной согласованной форме** (обычно минус-цилиндр, как в большинстве прайсов) и явно помечать, если бланк был в плюс-цилиндре.

### Практические следствия (3 варианта)

- При |SPH| низком и CYL≈0: practical может оставаться на индексе 1.50–1.56.
- При |CYL| ≥ ~1.50: поднимать комфорт/дизайн (aspheric/freeform) в optimal/premium раньше, чем «гнать» только индекс.
- Не обещать «одинаковую толщину OD и OS» при анизометропии.

---

## 3. ADD (аддидация)

### FACT

**ADD** — добавка для близи относительно коррекции дали, типично для пресбиопии. Указывается одним значением или отдельно OD/OS; обычно 0.75–3.50 D. [SRC-RX-004]

ADD используется в прогрессивах, офисных (дегрессия/office), бифокалах и иногда в SV near (как «SPH + ADD» для чисто ближних очков).

### EXPERT_JUDGMENT

Наличие ADD без возраста/жалоб/режима ношения — сигнал уточнить задачу (постоянно / только близь / компьютер). Отсутствие ADD у клиента 45+ не запрещает офисные/прогрессивные *обсуждения*, но финальный заказ без измерений и подтверждённого рецепта — только оценка класса.

---

## 4. PD — межзрачковое расстояние

### FACT

- **PD (pupillary distance)** — расстояние между центрами зрачков, мм.
- **Бинокулярное PD** — одно число (например 63).
- **Монокулярное PD** — отдельно OD и OS от переносицы (например 31.5 / 31.5). [SRC-RX-005]

Для однофокальных линз часто достаточно бинокулярного PD; для прогрессивов и индивидуализированных дизайнов предпочтительны монокулярные PD и высота установки. [SRC-RX-005] [SRC-PROG-001]

### EXPERT_JUDGMENT

Онлайн-консультант **может** запросить PD для оценки, но **не должен** утверждать финальную центровку прогрессива без очной разметки/измерений.

### Практические следствия

- Нет PD → practical/optimal для SV допустимы как «оценка по рецепту»; для progressive — только класс + ценовой диапазон.
- PD «с приложения по селфи» — низкая надёжность; помечать `requires_verification`.

---

## 5. Призма и основание (prism / base)

### FACT

Призматическая коррекция задаётся величиной (Δ, призменные диоптрии) и направлением основания: BI / BO / BU / BD (к носу / к виску / вверх / вниз). [SRC-RX-006]

### EXPERT_JUDGMENT — эскалация

Любая призма в рецепте → **эскалация к оптометристу/мастеру**, не автоматический онлайн-заказ. В портфеле из 3 вариантов допустима лишь пометка «нужна очная проверка возможности изготовления».

---

## 6. VA (острота зрения)

### FACT

VA (visus) — острота зрения, часто в десятичной или Snellen-записи. На рецепте может быть «с коррекцией» / «без». [SRC-RX-007]

### EXPERT_JUDGMENT

Цифровой консультант **не интерпретирует VA как диагноз**. Низкая VA при сильной коррекции или расхождение жалоб и рецепта → эскалация.

---

## 7. Режим ношения: даль / близь / постоянно

### FACT

Рецепт может быть:
- **distance** — для дали;
- **near** — для близи (часто уже с учётом ADD);
- **constant / full-time** — постоянное ношение.

Тип линзы должен соответствовать задаче, а не только числам на бланке. [SRC-RX-008]

### Вопросы консультанта

1. Для чего очки: даль, близь, компьютер, постоянно, вождение?
2. Есть ли вторая пара / контактные линзы?
3. Возраст (для риска пресбиопии и детских ограничений)?

---

## 8. Сферический эквивалент (SE)

### FACT

Приближение: **SE ≈ SPH + CYL/2** (в согласованной цилиндрической форме). [SRC-RX-009]

SE полезен для грубой оценки «силы» и толщины, **не заменяет** полноценный торический заказ при значимом CYL.

### EXPERT_JUDGMENT

Использовать SE только как внутренний хинт движка (тонкость, индекс), не показывать клиенту как «ваш рецепт упрощён».

---

## 9. Почему толщина ≠ только SPH

### FACT

Толщина готовой линзы зависит от:
- SPH и CYL (и знака: минус толще по краю, плюс — в центре);
- диаметра заготовки и размера/формы оправы;
- эффективного диаметра (мини-блэнк, decentration);
- показателя преломления и дизайна (сферический / асферический);
- PD и центровки;
- призмы и базы кривизны. [SRC-MAT-001] [SRC-DES-001]

### Запрещённые упрощения

Нельзя говорить клиенту: «у вас −3.00, значит линза будет тонкой» без учёта оправы, CYL и индекса.

---

## 10. Влияние CYL и AXIS на изготовление

### FACT

Торическая поверхность требует ориентации по AXIS. Ошибка оси ухудшает коррекцию астигматизма. Высокий CYL увеличивает асимметрию толщины и чувствительность к разметке. [SRC-RX-010]

### EXPERT_JUDGMENT

При |CYL| ≥ 2.00 D усиливать рекомендацию точных измерений и (в premium) индивидуализированного/freeform дизайна.

---

## 11. PD и прогрессивы

### FACT

Для прогрессивов критичны монокулярные PD, высота зрачка (fitting height), pantoscopic tilt, CVD (vertex), wrap. Без них лаборатория использует стандартные параметры дизайна — результат может отличаться от индивидуального заказа. [SRC-PROG-001] [SRC-ROD-IFU-001]

### Практические следствия

Онлайн: предлагать **класс** прогрессива (standard / mid / individual) и **ценовой диапазон**, не финальный SKU «как будто уже размечен».

---

## 12. Что фото рецепта не даёт надёжно

### FACT / EXPERT_JUDGMENT

Фото бланка / скрин **не гарантирует**:
- отсутствие OCR-ошибок (знак, точка, AXIS 90 vs 60);
- актуальность рецепта;
- PD и посадочные параметры;
- режим ношения и жалобы;
- соответствие транспозиции цилиндра прайсу лаборатории;
- наличие скрытой призмы / примечаний врача.

### UNKNOWN / requires_verification

Точность конкретного OCR-пайплайна продукта — отдельная метрика; до калибровки все поля с фото = `requires_verification`.

## 13. Когда эскалировать к оптометристу / мастеру

Консультант **не ставит диагноз**. Эскалация — организационное правило безопасности заказа.

### Пороги (CONFIGURABLE, requires_owner_approval)

Ниже — **предложения по умолчанию**, не медицинский закон. Включать только после утверждения владельцем продукта.

| Условие (черновик) | Действие движка |
|--------------------|-----------------|
| \|SPH\| > 8.00 D | Эскалация; online — только ориентир по классу |
| \|CYL\| > 3.00 D | Эскалация / очная проверка |
| Анизометропия > 2.00 D (по SPH или SE) | Эскалация; предупреждение о разной толщине/весе |
| Призма в рецепте | Обязательная эскалация |
| Возраст < 14 лет | Эскалация; детский контроль миопии обычно вне прайса |
| ADD есть, но нет PD / высоты / задачи ношения | Не финализировать progressive/office |
| Рецепт старше N месяцев (N = config) | Уточнить актуальность; при сомнении — эскалация |
| Жалобы «двоение / головная боль / резкое ухудшение» | Не подбирать онлайн; к специалисту |

Пометки в JSON правил: `requires_owner_approval: true`, `confidence: expert_judgment`.

---

## 14. Портфель practical / optimal / premium

| Уровень | Логика относительно рецепта |
|---------|-----------------------------|
| **Practical** | Корректный тип линзы под задачу; индекс не ниже оптического минимума; базовое покрытие |
| **Optimal** | Лучший баланс тонкость/комфорт/цена для данного SPH/CYL/режима |
| **Premium** | Выше дизайн/индивидуализация/покрытия; оправдано при высоком CYL, анизометропии, прогрессиве, безободковой оправе |

Все три варианта обязаны уважать hard constraints рецепта (диапазон SPH/CYL прайса, тип линзы).
