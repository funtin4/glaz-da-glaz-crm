# Глаз Да Глаз

Репозиторий салона оптики «Глаз Да Глаз».

## Состав

| Путь | Что это |
|------|---------|
| `index.html` | CRM 3.4 (заказы, клиенты, бланки) — локально в браузере |
| `advisor/` | **Lens Path** — цифровой подборщик линз |
| `data/` | Единая база знаний по прайсам + сырые HTML |
| `docs/` | Аудит продукта и архитектура |

## CRM

Откройте `index.html` в браузере. Данные — в localStorage; перед обновлением — «Сохранить базу».

## Цифровой консультант (новое)

```bash
cd advisor
npm install
npm run dev
```

Клиентский сценарий: консультант создаёт ссылку в `/staff` → клиент проходит мастер → получает 3 варианта.

Подробности: [`advisor/README.md`](advisor/README.md), критика ТЗ: [`docs/PRODUCT_AUDIT.md`](docs/PRODUCT_AUDIT.md).
